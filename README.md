# Career Knowledge Base

> Construindo soluções de dados que transformam informação em conhecimento.

## Sobre este repositório

Este repositório é a base de conhecimento da minha carreira.

Mais do que um currículo, ele documenta minha forma de pensar, meus princípios técnicos, minha evolução profissional, os projetos que desenvolvi e a maneira como abordo problemas relacionados a Dados, Analytics, Engenharia de Dados, Automação e Inteligência Artificial.

O objetivo é manter um histórico vivo da minha experiência profissional, permitindo que esse conhecimento seja reutilizado para:

- geração de currículos personalizados;
- análise de aderência a vagas;
- preparação para entrevistas;
- documentação da minha evolução técnica;
- organização dos meus projetos;
- planejamento da minha carreira.

Este repositório é atualizado continuamente conforme novos projetos, tecnologias e aprendizados surgem.

# Missão Profissional

Construir soluções que reduzam a distância entre dados e tomada de decisão.

Acredito que dados só geram valor quando conseguem produzir conhecimento confiável para as pessoas que precisam decidir.

Por isso meu foco não está apenas na construção de dashboards ou análises, mas em toda a jornada da informação:

- origem dos dados;
- integração;
- modelagem;
- transformação;
- padronização;
- disponibilização;
- consumo.

Meu objetivo é criar soluções que sejam confiáveis, reutilizáveis e fáceis de evoluir.

# Filosofia de Trabalho

Sempre procuro entender o sistema antes de modificar qualquer parte dele.

Ao receber um novo problema, normalmente sigo este fluxo:

```text
Problema

↓

Entendimento do negócio

↓

Mapeamento das fontes de dados

↓

Compreensão da arquitetura atual

↓

Identificação de gargalos

↓

Definição do cenário ideal

↓

Plano incremental de melhoria

↓

Automação

↓

Padronização

↓

Validação com usuários

↓

Evolução contínua
```

Meu objetivo nunca é apenas entregar uma demanda.

Meu objetivo é construir uma solução que continue funcionando mesmo quando surgirem novas demandas.
