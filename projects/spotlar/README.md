# Spotlar

Esta pasta documenta a evolução da plataforma de dados da Spotlar.

Cada documento representa uma iniciativa importante na evolução da arquitetura de dados da empresa. O foco não é descrever tecnologias, mas registrar os problemas enfrentados, as decisões tomadas, a arquitetura construída e os aprendizados obtidos ao longo do processo.

## Estrutura

- Uma iniciativa por documento.
- Cada documento deve contar uma única história.
- As tecnologias aparecem como consequência das decisões arquiteturais, e não como protagonistas.
