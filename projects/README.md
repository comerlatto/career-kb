# Projetos

Esta pasta reúne os principais projetos da minha carreira.

O objetivo não é apenas registrar o que foi desenvolvido, mas documentar o contexto, as decisões tomadas, os desafios encontrados, os resultados obtidos e os aprendizados de cada iniciativa.

Cada projeto deve responder às seguintes perguntas:

- Qual problema precisava ser resolvido?
- Qual era o contexto?
- Quais decisões técnicas foram tomadas?
- Quais alternativas foram consideradas?
- Qual foi o resultado?
- O que aprendi?
